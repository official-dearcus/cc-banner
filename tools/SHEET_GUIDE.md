# 구글시트에 추가할 것 (2026-08-11 ~ 09-01 작업분)

기존 시트는 **그대로 두셔도 됩니다.** 아래는 전부 선택 항목이고,
비어 있으면 지금까지와 똑같이 동작합니다. 필요한 것만 골라 쓰세요.

이벤트 배너를 안 쓰면 만들지 않아도 됩니다.

## 2. 기존 탭에 추가할 열

### ProductMaster

| 열 | 값 | 언제 쓰나 |
|---|---|---|
| `enabled` | TRUE / FALSE | **FALSE** 면 옵션 카드에서 빠지고, 써볼래요 경품 후보로만 뜬다. 옵션으로 안 파는 단품 |
| `scentUrl` | 이미지 주소 | 향 안내 섹션. 넣으면 상세 옵션 아래 + 피드에 붙는다 (에어비움) |
| `colorRatio` | 숫자 (예 1.8) | 컬러 칩 가로/세로. **안 넣어도 됨** — 실제 사진 비율을 자동으로 읽는다 |
| `colorRowGap` | 숫자 (예 20) | 컬러 칩 행 간격. 안 넣으면 기본값 |

### ColorMaster

| 열 | 값 | 언제 쓰나 |
|---|---|---|
| `lineLabel` | 그란데 / 스탠다드 | 줄 이름. 안 넣으면 코드의 기본 목록에서 찾는다 (kids·adult·grande·standard 는 이미 있음) |
| `defaultOn` | TRUE / FALSE | 처음 켜둘 색. 한 줄에서 하나라도 TRUE 면 그 줄은 TRUE 인 것만 켜짐 |
| `colorGrid` | shared / lines | 칩 배치. **안 넣어도 됨** — 사진 주소가 겹치면 자동으로 한 벌(2열) |
| `colorRatio` `colorRowGap` | 숫자 | ProductMaster 대신 여기 넣어도 된다. 그 제품군 아무 행에나 한 번만 |

### TemplateMaster

| 열 | 값 | 언제 쓰나 |
|---|---|---|
| `scentUrl` | 이미지 주소 | 템플릿마다 향 사진을 다르게 할 때. 같으면 ProductMaster 쪽이 편함 |

### HeroMaster

| 열 | 값 | 언제 쓰나 |
|---|---|---|
| `theme` | green / pink / blue … | 그 테마를 고르면 이 사진이 자동으로 잡힌다. 소문자 |

## 3. 새 제품라인을 등록할 때

`TemplateMaster` 에 세 줄만 넣으면 템플릿 3개가 자동으로 붙습니다.

```
groupKey   templateId    enabled
soapy      soapy_01      TRUE
soapy      soapy_02      TRUE
soapy      soapy_03      TRUE
```

- 번호는 **`01` · `02` · `03`** 두 자리. `_1`, `_04` 는 오류
- 제품군키에 **밑줄 금지** (`bath_soap_01` ✗ → `bathsoap_01`)
- `bamboo` 로 시작하면 구형 렌더러로 간다 — 새 라인은 다른 이름으로
