섹션 순서 — 구형(뱀부 01·02)과 인스타 피드까지 확장 (요청 2026-08-28)

1) 구형 렌더러도 순서 변경 (13-render-core)
   히어로·옵션·이벤트 세 덩어리로 나눠 신형과 같은 방식으로 옮겨 그린다.
     ⚠ hero01/02 와 옵션 묶음은 y 인자가 없다(절대좌표) → ctx.translate 로 옮긴다.
       그리는 내용은 안 건드렸다.
     legacyOption() / legacyOptionH() 로 옵션 묶음을 떼어냈다.
     legacyBodyH() 는 쓰이지 않게 되어 지웠다.
   구형엔 향·컬러 섹션이 없으므로 패널에서 그 둘은 숨긴다.
   숨긴 섹션은 저장값에 그대로 남는다 — 신형 제품군으로 돌아가도 안 잃는다.

2) 인스타 피드도 상세와 같은 순서
   신형  nvFeedPlan 이 nvSecOrder 를 따라 묶음 단위로 이어 붙인다.
         한 섹션이 여러 장일 수 있다(옵션 N장 · 이벤트 M장).
         ⚠ 사이즈 안내는 상세에 없는 섹션이라 옵션 묶음 바로 뒤에 붙인다.
   구형  legacyFeedPlan() 신설. drawFeedSlide 가 인덱스 대신 이 목록을 본다.

   검증 — 순서를 바꾸면 상세 y 와 피드 장 순서가 함께 따라간다
     구형  hero → opt → event   ⇒  event → hero → opt
     신형  hero → opt → scent → color → event
           ⇒  event → color → scent → opt → hero
   캔버스 높이는 순서와 무관하게 그대로다(구형 2463 확인).
