  새로 그리는 대신 신형(누볼라) 03 을 패밀리와 무관하게 쓰도록 갈랐다.
    nvIsOn()            curFam()==="nuvola" || state.tpl==="03"
    themeTable(fam,"03") → 항상 THEMES_NUVOLA
    tplMeta(fam,"03")    → 항상 "03 · 그리드형"
  → 뱀부 03 = 누볼라 03 과 같은 화면. 뱀부 01·02 는 구형 그대로 안 건드렸다.

색상 데이터가 없는 제품군은 상세에서 컬러 섹션을 통째로 생략 (nvColorH)
  예전엔 hasColors() 와 무관하게 K.H 를 더해 빈 섹션이 붙었다.
  피드(nvFeedSlide)는 이미 걸렀는데 상세만 안 걸러져 있었다.
  뱀부처럼 색이 없는 제품군에서 03 을 쓰면 이게 바로 드러난다.

  before  KNOWN_TPL = ["bamboo500_01", ...] 손으로 등록. 새 라인은 전부 E302.
  after   isKnownTpl(id) = /^[A-Za-z0-9][A-Za-z0-9-]*_(01|02|03)$/
  → 시트에 <제품군키>_01/_02/_03 만 넣으면 새 제품라인이 템플릿 3개를 자동으로 받는다.
  오타(_1, _04, 언더바 없음)는 여전히 E302 로 걸린다.
  KNOWN_TPL 은 { includes: isKnownTpl } 로 남겨 09-hero-color 호출부를 그대로 뒀다.
