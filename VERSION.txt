ProductMaster.enabled 신설 — 옵션 외 단품을 시트에서 관리 (제안 2026-09-01)
  C 에서는 GiftMaster 나 직접 입력으로 넣게 했는데, 같은 제품군의 제품이면
  ProductMaster 에 두는 편이 이름·사진을 한 곳에서 보게 되어 낫다.

    ProductMaster … | enabled |
                      TRUE  또는 빈칸 → 지금까지와 같다 (옵션 카드에 나온다)
                      FALSE           → 옵션 카드에서 빠진다. 행은 살아 있어서
                                        써볼래요 경품 후보로는 계속 뜬다.

  07-sheet-sync 가 g.rows(옵션)와 g.offRows(옵션 외)로 나눠 넘긴다.
  드롭다운 묶음이 넷이 됐다 —
    제품군 제품 · 옵션 외 단품 · 선물 목록 · 직접 입력…
  경품 저장값 kind 에 "off" 추가. row 와 번호가 안 섞이게 따로 센다.
  ⚠ enabled 열이 없는 기존 시트는 전부 TRUE 로 읽힌다 — 그대로 동작한다.

써볼래요 경품 — 옵션에 없는 단품도 넣을 수 있게 (요청 2026-09-01)
  A/B 는 제품군의 옵션 제품만 후보였다. 드롭다운을 셋으로 나눴다.
    제품군 제품   지금 제품군의 옵션 (예전과 같음)
    선물 목록     GiftMaster — 옵션에 없는 단품은 보통 여기 있다
    직접 입력…    이름 + 사진 주소를 그 자리에서 입력
  이름은 문장에, 사진은 카드 이미지에 들어간다. 조사도 이름 기준으로 다시 고른다.

  저장 모양이 바뀌었다  e.rowIdx(숫자) → e.pick { kind, … }
    kind: row(i) | gift(key) | custom(name, url)
    ⚠ 예전 저장분은 tryPick() 이 rowIdx 를 row 로 바꿔 읽는다 — 안 깨진다.

  ⚠ 직접 입력 중 커서가 튀던 문제
    draw() 가 패널을 다시 그리는데, 타이핑 중이면 DOM 이 새로 만들어져
    커서가 맨 뒤로 갔다. 입력칸에 포커스가 있으면 다시 안 그린다.
